Organizzazione cartelle Spring

Separazione per responsabilità, simile al progetto Spring di riferimento.

config/ · configurazioni controller/ · REST API dto/ · contratti HTTP entity/ · modello JPA enums/ · ruoli e stati repository/ · query dati service/ · logica applicativa common/ · errori condivisi

Confini importanti

  • I controller restituiscono DTO, non entità JPA.
  • I service coordinano validazione e transazioni.
  • I repository sono l'accesso ai dati; Hibernate usa ddl-auto=validate.
  • Le API pianificate in OpenAPI non sono endpoint già disponibili.
