# Template Scrum

Usare una sezione per ogni evento realmente svolto. Non retrodatare verbali o
dedurre risultati da commit. Ogni esito deve avere una prova identificabile.
Per i criteri generali di completamento vedere
[Definition of Done](../11_DEFINITION_OF_DONE.md).
